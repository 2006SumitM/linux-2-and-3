PRACTICAL 2(A) - Basic Linux Commands

Step 1: List files
ls

Step 2: Long listing
ls -l

Step 3: Show hidden files
ls -a

Step 4: Show files with detailed information
ls -la

Step 5: Display current directory
pwd

Step 6: Change directory
cd dirname

Example:
cd Documents

Step 7: Create a directory
mkdir project

Step 8: Create an empty file
touch file1.txt

Step 9: Display file contents
cat file1.txt

Step 10: Create/write into a file using cat
cat > file1.txt
Type the text
Press Ctrl + D to save

Step 11: Append text to a file
cat >> file1.txt
Type additional text
Press Ctrl + D

Step 12: Copy a file
cp file1.txt file2.txt

Step 13: Copy a file into a directory
cp file1.txt project/

Step 14: Move or rename a file
mv file1.txt newfile.txt

Step 15: Remove a file
rm newfile.txt

Step 16: Remove an empty directory
rmdir project

Step 17: Create nested/directories as required
mkdir dirname

Step 18: View directory contents again
ls
