PRACTICAL 3(C) - Creating, Deleting, Copying and Moving Files/Directories

Step 1: Create a directory
mkdir classroom

Step 2: Enter the directory
cd classroom

Step 3: Create a file
touch file1.txt

Step 4: Create another file
touch file2.txt

Step 5: Display files
ls

Step 6: Write content into a file
cat > file1.txt
Enter text
Press Ctrl + D

Step 7: Display file contents
cat file1.txt

Step 8: Copy a file
cp file1.txt copy1.txt

Step 9: Copy a file into another directory
mkdir backup
cp file1.txt backup/

Step 10: Move / rename a file
mv file2.txt newfile.txt

Step 11: Delete a file
rm newfile.txt

Step 12: Delete an empty directory
rmdir backup

If directory contains files:
rm -r backup

Step 13: Return to parent directory
cd ..
